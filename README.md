# WayPoint AI

Фото локации или запрос в чат → ИИ генерирует поездку, маршруты и метки на карте, расписывает отдых по часам (где поспать, поесть, что посмотреть).

- **Домен:** `waypoint.crlx1q.com` (API на `/api`, админка на `/admin`)
- **Стек:** Node.js (Express) + MongoDB Atlas + Gemini · лендинг + админ-SPA · Flutter-приложение

## Структура

| Папка | Что внутри |
|---|---|
| `server/` | API, ИИ-агент, лендинг (`public/`), админка (`public/admin/`) |
| `app/` | Flutter-приложение (Android + web) |

## Запуск сервера

```bash
cd server
npm install
npm run dev   # или npm start
```

Сервер слушает `0.0.0.0:8080` и печатает в терминал все IP (локальный и сетевой), статус MongoDB и Gemini.

### .env (`server/.env`)

| Переменная | Описание |
|---|---|
| `MONGODB_URI` | Строка подключения MongoDB Atlas (`mongodb+srv://...`). Если пусто — поднимется in-memory Mongo для разработки |
| `GEMINI_API_KEY` | Ключ Google AI Studio |
| `GEMINI_MODEL` | Модель (по умолчанию `gemini-3.1-flash-lite`, есть автофолбэк) |
| `UNSPLASH_ACCESS_KEY` | Ключ Unsplash (фолбэк для фото, опционально) |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | Админ создаётся автоматически при первом запуске |
| `APK_URL` | Ссылка для кнопки «Скачать» на лендинге |

## Приложение (Flutter)

```bash
cd app
flutter pub get
flutter run --dart-define=API_BASE=http://<IP-из-терминала-сервера>:8080
```

По умолчанию приложение ходит на `https://waypoint.crlx1q.com`. Адрес сервера также можно сменить прямо в приложении: **Profile → Сервер**.

Сборка APK: `flutter build apk --release`, затем положить файл в `server/public/downloads/waypoint-ai.apk` — кнопка «Скачать» на лендинге начнёт работать.

## Как работает ИИ-агент

1. Пользователь пишет текст или прикладывает **фото локации** (Gemini vision распознаёт место).
2. Агент через function calling дергает инструменты сервера: геокодинг (Nominatim), реальные отели/кафе/достопримечательности со звёздами (OSM Overpass), прогноз погоды (Open-Meteo), реальные фото мест (Wikimedia Commons), справку (Wikipedia).
3. Агент задаёт 1–2 уточняющих вопроса и показывает **карточку-предложение тура**.
4. После принятия сервер генерирует полный план: почасовой таймлайн по дням с учётом погоды, маршруты (OSRM), фото, deep-link'и в Google Maps. Всё сохраняется в MongoDB.

Все внешние данные кэшируются в Mongo, чтобы не упираться в лимиты бесплатных API.

## Деплой на Koyeb

- Build: `cd server && npm install`
- Run: `node src/index.js`
- Переменные окружения — из таблицы выше (обязательно `MONGODB_URI` от Atlas)
- Порт: `8080` (Koyeb пробрасывает автоматически, слушаем `0.0.0.0`)

## Админка

`/admin` — логин из `.env`. Дашборд (статистика, график поездок, топ направлений), пользователи, поездки (просмотр плана), чаты с ИИ (с трассировкой инструментов), композер уведомлений (база под Firebase push), настройки (модель Gemini, лимиты, режим обслуживания).
